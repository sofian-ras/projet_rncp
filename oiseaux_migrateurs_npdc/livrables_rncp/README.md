## Règle de soutenance

Pour chaque bloc, présenter dans cet ordre:
1. Objectif RNCP
2. Ce qui est implémenté
3. Où le prouver dans le code
4. Commande de démonstration
5. Livrable attendu (fichier/écran/API)
6. Statut (OK / Partiel / À compléter)
